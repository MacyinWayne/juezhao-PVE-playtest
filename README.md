# 江湖残局 · 抉招：江湖录

《抉招：江湖录》的**跑团战斗环节试玩 / 高难挑战**：一局残局，一场没退路的过招。

- 纯网页、手机优先，点开即玩；无需登录、无内购、无联网。
- 每个「战斗剧本」是一套独立的敌人配置与卡组；**当前开放剧本一「罐中鲨」**，更多剧本筹备中。
- 全部内容为《抉招：江湖录》原创设定与卡牌数据。

## 怎么玩

1. **看意图**：敌人头顶会预告它这回合要做的事——进取＝攻击，保守＝防御，灵活＝闪避或召唤。先看到，就能针对。
2. **出牌**：每回合最多打 5 张。卡牌按进取／保守／灵活／隐藏分路，打出顺序可以用来凑秘笈。
3. **结算**：你的伤害先结算，敌人的行动后结算——所以「消掉它的意图」「叠够防御」都是解题方式。
4. **秘笈**：五张秘笈不在牌库里、始终可看；本回合打出的标记**连续包含**它的要求，就能发动（每回合限 1 张）。

## 本地打开

直接双击 `index.html` 即可；或在这个目录起一个静态服务器：

```powershell
node tools/serve.mjs
```
